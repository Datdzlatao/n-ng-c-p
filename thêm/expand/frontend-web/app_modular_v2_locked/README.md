# Frontend Modular V2 (Locked / Lưu Trữ)

Thư mục này lưu trữ nguyên vẹn toàn bộ mã nguồn của đợt phân rã Frontend Dashboard (`app/`) thành các mô-đun độc lập:
- `css/`: Các file style theo từng thành phần (`base.css`, `cards.css`, `modals.css`, `responsive.css`, `roles.css`, `tables.css`, `toast.css`, `variables.css`).
- `js/`: Các file logic ES module xử lý State, API, Routing, Navigation, Auth, Export QR, Audio, Connection.
- `views/`: Các view phân hệ (Admin, Principal, Teacher, Student, Parent).
- `modals/`: Các template modal popup độc lập.

Bản này được khóa lại và bảo lưu an toàn để người dùng có thể tham khảo, thử nghiệm hoặc kích hoạt lại trong tương lai mà không làm mất bất kỳ dòng code nào.

Đóng vai một Senior Backend & AI Engineer. Hãy giúp tôi xây dựng từ con số 0 một hệ thống Backend quản lý thông minh tích hợp AI Agent thông qua giao thức MCP (Model Context Protocol).

1. TECH STACK YÊU CẦU:
- Ngôn ngữ: Python 3.11+
- Web Framework: FastAPI (hỗ trợ REST API và WebSocket thời gian thực).
- Giao thức AI: Sử dụng thư viện `mcp` chính thức (FastMCP) để xây dựng MCP Server và tích hợp với Google Gemini API (`google-genai`) làm MCP Client/Host.
- Cơ sở dữ liệu: Supabase (PostgreSQL) sử dụng thư viện `supabase-py`.
- Tác vụ chạy ngầm: `asyncio` kết hợp `APScheduler` để giám sát dữ liệu và lịch trình 24/7.

2. CẤU TRÚC DATABASE (SUPABASE SCHEMA):
Hệ thống gồm 4 bảng chính:
- `env_logs`: id, temperature (float), humidity (float), created_at (timestamp) - Lưu thông số cảm biến môi trường.
- `inventory`: id, item_name (text), quantity (float), unit (text), min_threshold (float), location (text), updated_at (timestamp) - Quản lý kho vật tư.
- `schedules`: id, task_name (text), target_date (date), status (text: 'pending'/'done'), note (text) - Lịch trình nhập vật tư/chăm sóc.
- `alerts`: id, alert_type (text), message (text), is_read (bool), created_at (timestamp) - Lưu lịch sử cảnh báo bất thường.

3. KIẾN TRÚC MCP CẦN XÂY DỰNG:
Hãy thiết kế một MCP Server (`mcp_server.py`) sử dụng `FastMCP` cung cấp các thành phần sau cho AI:
- MCP Resources (Đọc ngữ cảnh):
  + `resource://env/latest`: Lấy 10 bản ghi môi trường mới nhất từ bảng `env_logs`.
  + `resource://inventory/low-stock`: Lấy danh sách vật tư có số lượng chạm hoặc thấp hơn `min_threshold`.
- MCP Tools (Cánh tay thực thi CRUD):
  + `manage_inventory(action, item_name, quantity, unit, location)`: Thêm mới, cộng/trừ số lượng hoặc sửa vật tư trong kho (có kiểm tra tồn kho trước khi xuất).
  + `manage_schedule(action, task_name, target_date, note)`: Tạo hoặc cập nhật lịch trình.
  + `create_system_alert(alert_type, message)`: Ghi cảnh báo vào bảng `alerts` và kích hoạt phát thông báo qua WebSocket.

4. LUỒNG CHẠY NGẦM & REALTIME (FASTAPI):
- WebSocket Manager: Quản lý kết nối từ Web và Mobile App để đẩy tin nhắn chat và popup cảnh báo theo thời gian thực.
- The Watcher (Background Task): Vòng lặp bất đồng bộ kiểm tra 2 bản ghi `env_logs` mới nhất. Nếu chênh lệch đột biến hoặc vượt ngưỡng, tự động gửi dữ liệu cho Gemini đánh giá và gọi tool `create_system_alert`.
- Scheduler: Mỗi sáng tự động quét bảng `schedules` và `inventory`, kết hợp Gemini tạo lời nhắc thông minh đẩy qua WebSocket.

5. CÁCH CHÚNG TA LÀM VIỆC (QUAN TRỌNG):
Không viết toàn bộ code trong 1 lần trả lời. Hãy đi từng bước (Phase) và đợi tôi xác nhận chạy thành công mới sang bước tiếp theo:
- Phase 1: Thiết lập cấu trúc thư mục chuẩn (Clean Architecture), file `requirements.txt`, file `.env.example` và module kết nối Supabase.
- Phase 2: Viết code hoàn chỉnh cho `mcp_server.py` (định nghĩa đầy đủ Tools và Resources).
- Phase 3: Kết nối Gemini với MCP Server và tạo API/WebSocket trên FastAPI để chat điều khiển database.
- Phase 4: Viết Background Task (Watcher & Scheduler) tự động giám sát và bắn cảnh báo.
